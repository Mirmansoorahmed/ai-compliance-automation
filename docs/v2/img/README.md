# Diagram images for docs/v2

Two PNGs belong in this folder and are referenced by the v2 docs:

- `architecture-v2.png` — the layered v2 architecture (referenced by
  [`../ARCHITECTURE.md`](../ARCHITECTURE.md) section 2).
- `request-flow-v2.png` — the three request-flow stories (CV screening → WARN,
  social scoring → BLOCK, secret → BLOCK), referenced by `ARCHITECTURE.md`
  section 1.

These are binary image files from the v2 design pack. They are added by the
repository owner (who holds the source files); this agent environment received
them only as rendered images, not as file bytes, so the binaries are not
committed here. The Mermaid/source diagrams can also be regenerated from the
design pack. Until the PNGs are added, the links above will 404 on GitHub.
